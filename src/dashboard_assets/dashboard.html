ROTATING EQUIPMENT · EARLY WARNING SYSTEM

__TITLE__

과거 정상 운전과 현재 운전의 차이를 확인하고, 단기 흔들림과 장기 추세 변화를 같은 시간축에서 검증합니다.

결과 확인 중

01 / OVERVIEW

결과를 판단하는 두 가지 기준

정규화 복원 오차와 태그별 시점 일치율을 모두 만족해야 Phase 2 통과입니다.

시스템의 목적과 판단 흐름

  1. 센서 데이터 입력1분 간격의 진동, 베어링 온도, 윤활유, DGS, 공정 변수를 시간 순서대로 읽습니다. 진동 Spectrum은 사용하지 않습니다.
  2. 정상 운전 기준 학습정상 train 데이터로 정규화 기준과 TranAD 모델을 학습합니다. test 정답은 입력 특징, 복원값, 이상점수 생성에 사용하지 않습니다.
  3. 이상점수와 최종 Alarm현재 값과 복원값의 차이 등 구현된 점수를 태그별 기준과 비교합니다. 운영용 정지 여부는 센서로 별도 판정합니다.
  4. 동일 시점 검증최종 Alarm과 Alarm_{Tag}, 센서 기반 정지 판정과 Inhibit 정답을 각각 비교합니다. 정답은 결과 확인용입니다.

이번 실행의 설정

전체 실행 설정 보기
이 페이지는 저장된 실행 결과를 표시합니다. 센서 수집 서버에 연결된 실시간 운영 화면이 아니며, 그래프 확대·이동은 원본 결과를 탐색하는 기능입니다.
평가 원칙
MAE는 학습 데이터로 정규화한 전체 Test의 실제값과 복원값 간 평균 절대 오차입니다. 태그별 일치율은 같은 시점의 Label과 최종 Alarm을 1:1 비교합니다. 정상 시점이 많으면 일치율이 높아질 수 있으므로 재현율, 정밀도, F1과 혼동행렬을 함께 확인합니다. 시간을 앞뒤로 이동하거나 이벤트 구간 전체를 정답으로 바꾸는 보정은 이 대시보드에서 수행하지 않습니다.

지표 읽는 방법
일치율
(TP + TN) / 정답을 알고 있는 비교 시점 수. 각 Tag가 95% 이상이어야 합니다. pipeline과 같은 known-label 기준이며 누락 수·Coverage는 별도 경고로 표시합니다.
재현율
실제 이상 중 Alarm이 울린 비율. FN이 많으면 실제 이상을 놓칩니다.
정밀도
발생한 Alarm 중 실제 이상 비율. FP가 많으면 불필요한 Alarm이 늘어납니다.
미정
정답이나 예측을 전혀 비교할 수 없거나 지표의 분모가 0인 경우입니다. 누락 시점을 정상으로 간주하지 않습니다.
