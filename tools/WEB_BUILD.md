# 정적 웹 결과 빌드

Node.js 22 이상에서 의존성 설치 없이 실행합니다.

```text
node tools/build-site.mjs
node tools/verify-site.mjs
```

빌드 입력은 Git LFS의 `reports/EWS_final_offline.html` 하나입니다. 파일이
체크아웃되지 않아 LFS 포인터만 있으면 공개 GitHub LFS URL에서 읽습니다.
240,070,294 bytes 및 고정 SHA-256이 모두 일치해야 빌드를 계속합니다.
원본은 수정하지 않고 `site/`만 생성합니다. Vercel 출력 디렉터리는 `site`입니다.

`site/index.html`은 두 화면의 작은 탐색 틀입니다. 요약의 실험·코드 목록은
해당 목록을 펼칠 때, 모델 대시보드의 전체 시각·정지 상태는 화면을 열 때,
Tag별 전체 시계열은 해당 Tag를 선택할 때 읽습니다. 저장된 실제 SHAP는
2026-06-03 14:00부터 10분에 해당하며 새로운 모델 계산을 제공하지 않습니다.

원본 JSON을 다시 직렬화하거나 수치를 줄이지 않습니다. 정확한 UTF-8 bytes를
8 MiB 이하로 나누고 gzip 압축하여 배포합니다. 브라우저는 같은 사이트에서만
파일을 받아 크기·SHA-256을 확인하고 압축을 푼 뒤 원문을 합칩니다.
최신 Chrome 또는 Edge가 필요합니다. 선택한 Tag의 원본 476,641시점을 기존
그래프 코드로 표시하며 확대·축소·CSV 내보내기와 3Tag 메모리 캐시를 유지합니다.

빌드 검증은 7Tag의 5개 전체 배열, 정지 중 Alarm 0, Tag별 혼동행렬, 전체 MAE,
평가 464개·보존 코드 162개, 원문/압축 복원의 SHA를 확인합니다. 독립 검증은
산출물의 SHA·크기, JavaScript 문법, 브라우저 읽기 계약과 선택하지 않은 Tag의
지연 로딩을 확인합니다. 실제 브라우저 화면·조작 검증은 배포 후 별도로 수행합니다.

이 사이트는 사용자 요청으로 공개된 최종 보고서와 실제 저장 데이터를 포함합니다.
학습 모델 서버, 원격 SageMaker 연결, 새 SHAP 계산 기능은 포함하지 않습니다.
학습·평가 코드의 실행 경로와 동작은 수정하지 않습니다.
